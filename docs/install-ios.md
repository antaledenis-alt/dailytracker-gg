# Установка на iPhone

Приложение распространяется как неподписанный файл `Planner.ipa`. Подпись выполняет SideStore с использованием обычного Apple ID. Платный аккаунт разработчика и компьютер Mac не нужны.

## Требования

| Компонент | Требование |
|---|---|
| iPhone | iOS 16.4 или новее, установлен код-пароль |
| Компьютер | Windows 10/11 (64-bit) или macOS — только для первичной установки |
| Учётная запись | Apple ID |
| Сеть | Wi-Fi |

## 1. Установка SideStore

Выполняется один раз. Подробная официальная инструкция: [docs.sidestore.io](https://docs.sidestore.io).

1. Установите на iPhone приложение **LocalDevVPN** из App Store и включите его.
2. Установите на компьютер **iTunes** (на Windows — из Microsoft Store) и **iLoader** со страницы SideStore.
3. Подключите iPhone кабелем и запустите iLoader.
4. Войдите в iLoader со своим Apple ID и установите SideStore.
5. На iPhone подтвердите доверие компьютеру и введите код-пароль.
6. Если система попросит, включите режим разработчика: **Настройки → Конфиденциальность и безопасность → Режим разработчика**, затем перезагрузите устройство.

## 2. Установка Планера

1. Откройте на iPhone в Safari страницу [Releases](https://github.com/antaledenis-alt/dailytracker-gg/releases/latest) и скачайте `Planner.ipa`.
2. Включите LocalDevVPN.
3. Откройте SideStore → **My Apps** → **+** и выберите скачанный файл в папке «Загрузки».
4. Запустите Планер и разрешите уведомления.
5. Проверьте уведомления: **шестерёнка → Проверить уведомление**.

## 3. Продление подписи

Подпись бесплатного Apple ID действует 7 дней. Приложение напоминает об окончании срока за 24 часа, 3 часа и 30 минут.

Продление вручную:

1. Включите LocalDevVPN.
2. Откройте SideStore → **My Apps** → **Refresh All**.
3. Откройте Планер, чтобы он прочитал новый срок подписи.

Продление можно полностью автоматизировать — см. [no-7-day-limit.md](no-7-day-limit.md#1-автоматическое-продление-через-sidestore).

Если срок всё же истёк, приложение перестанет запускаться, но данные сохранятся. После продления подписи оно снова откроется.

## 4. Обновление

Скачайте новый `Planner.ipa` из Releases и установите его через SideStore поверх текущей версии. Задачи и настройки сохраняются.

## Ограничения бесплатного Apple ID

| Ограничение | Значение |
|---|---|
| Срок действия подписи | 7 дней |
| Одновременно установленных приложений через SideStore | 3, включая сам SideStore |
| Новых идентификаторов приложений в неделю | 10 |

## Известные особенности

- Кнопки «Готово» и «+10 минут» в уведомлении обрабатываются, если приложение находится в фоне. Если его полностью закрыли, iOS может не передать нажатие. В этом случае отметьте задачу в приложении.
- В статистике учитываются только завершённые задачи.
