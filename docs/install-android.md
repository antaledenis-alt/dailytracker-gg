# Установка на Android

На Android приложение устанавливается напрямую из файла `Planner.apk`. Компьютер, магазин приложений и продление подписи не нужны.

## Требования

| Компонент | Требование |
|---|---|
| Android | 7.0 или новее |
| Архитектура | arm64-v8a или armeabi-v7a (практически все телефоны) |

## Установка

1. Откройте на телефоне страницу [Releases](https://github.com/antaledenis-alt/dailytracker-gg/releases/latest) и скачайте `Planner.apk`.
2. Откройте скачанный файл. Если система попросит, разрешите установку из этого источника: **Настройки → Приложения → Специальный доступ → Установка неизвестных приложений**, выберите браузер и включите разрешение.
3. Нажмите **Установить**. Google Play Защита может показать предупреждение о неизвестном разработчике — выберите **Всё равно установить**.
4. Запустите Планер и разрешите уведомления.

## Точные напоминания

Чтобы напоминания приходили минута в минуту, приложению нужно разрешение на точные будильники. Обычно оно выдаётся автоматически. Если напоминания опаздывают:

1. Откройте **Настройки → Приложения → Планер**.
2. Включите **Будильники и напоминания**.
3. Отключите оптимизацию батареи для Планера: **Батарея → Без ограничений**.

На смартфонах Xiaomi, Huawei, Honor, Samsung дополнительно разрешите автозапуск и работу в фоне, иначе система может откладывать уведомления.

## Обновление

Скачайте новый `Planner.apk` и установите его поверх текущей версии. Задачи и настройки сохраняются.

## Примечание о подписи

APK подписан отладочным ключом из шаблона Expo. Для личного использования этого достаточно, а обновления устанавливаются поверх, пока ключ не меняется. Для публикации в Google Play понадобится собственный ключ.
