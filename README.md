# Планер — личный планер дня для iPhone

Таймлайн дня с цветными блоками задач, напоминания (включая настойчивые), отметки «вовремя / позже / пропущено», обзор двух недель и итоги продуктивности. Все данные хранятся только на телефоне.

---

## Как поставить на iPhone — бесплатно и без Mac

Понадобится: компьютер с Windows, кабель для iPhone, Wi‑Fi, обычный Apple ID и аккаунт на GitHub.

### Шаг 1. Выложить проект на GitHub (один раз)

0. **Важно:** в папке проекта переименуй папку `_github` в `.github` (с точкой в начале). В ней лежит инструкция облачной сборки. Если Windows не даёт так назвать папку, введи имя `.github.` с точкой в конце: точка в конце исчезнет сама.
1. Зарегистрируйся на [github.com](https://github.com).
2. Установи [GitHub Desktop](https://desktop.github.com) и войди в свой аккаунт.
3. В GitHub Desktop выбери **File → Add local repository…** и укажи эту папку (`dailytracker-gg`). Программа предложит создать репозиторий — нажми **create a repository**, затем **Create repository**.
4. Нажми **Publish repository**. Галочку **Keep this code private** лучше снять: для публичных репозиториев облачные сборки бесплатны без ограничений. В коде нет личных данных: задачи живут только на телефоне.

### Шаг 2. Собрать приложение в облаке

1. На странице репозитория на github.com открой вкладку **Actions**.
2. Слева выбери **Сборка для iPhone** и нажми **Run workflow**. Сборка также запускается сама после каждой публикации изменений.
3. Через 20–30 минут появится зелёная галочка, а в разделе **Releases** справа на главной странице репозитория — файл **Planner.ipa**.

### Шаг 3. Установить SideStore (один раз)

SideStore — приложение, которое ставит программы с бесплатной подписью и продлевает её прямо с телефона. Подробная официальная инструкция: [docs.sidestore.io](https://docs.sidestore.io).

1. На iPhone должен быть включён код-пароль.
2. Установи из App Store приложение **LocalDevVPN** и включи его.
3. На компьютер установи **iTunes** (из Microsoft Store) и программу **iLoader** со страницы SideStore.
4. Подключи iPhone кабелем, запусти iLoader, войди со своим Apple ID и установи SideStore. На телефоне нажми «Доверять» и введи код-пароль.
5. Если iPhone попросит, включи **Настройки → Конфиденциальность и безопасность → Режим разработчика** и перезагрузи телефон.

### Шаг 4. Поставить Планер

1. На iPhone открой страницу **Releases** своего репозитория в Safari и скачай **Planner.ipa**.
2. Открой SideStore → вкладка **My Apps** → **+** и выбери скачанный файл. Можно и так: в «Файлах» нажми на `Planner.ipa` → «Поделиться» → SideStore.
3. Открой Планер и разреши уведомления. В настройках приложения (шестерёнка) есть кнопка «Проверить уведомление».

### Каждые 7 дней — продлить подпись

Бесплатная подпись действует 7 дней. Планер сам напомнит об этом **за сутки, за 3 часа и за 30 минут** до срока. Как продлить:

1. Включи LocalDevVPN.
2. Открой SideStore → **My Apps** → **Refresh All**.
3. Открой Планер: он увидит новый срок и перенастроит напоминания.

Компьютер для продления не нужен. Если подпись всё же истекла, данные не пропадут: обнови подпись, и приложение снова откроется.

### Как обновить приложение

Когда в проекте появляются изменения, опубликуй их в GitHub Desktop (**Commit → Push**). Сборка запустится сама. Скачай новый `Planner.ipa` из Releases и установи его через SideStore поверх старой версии — задачи сохранятся.

## Что умеет версия 0.1

- **Сегодня:**
  - таймлайн с 6:00 до 24:00 с сеткой по 30 и 60 минут и красной линией «сейчас»;
  - у каждой категории свой цвет, иконка и фактура (линии, точки, сетка, диагональ, волны).
- **Управление задачами на таймлайне:**
  - тап по пустому месту — новая задача на это время;
  - тап по задаче — шторка с действиями;
  - долгое нажатие и перетаскивание — перенос с привязкой к сетке 30 минут;
  - кружок справа — быстрая отметка выполнения;
  - свайп влево и вправо — соседний день.
- **Статусы:**
  - запланировано, идёт сейчас, выполнено вовремя, выполнено позже, пропущено;
  - задача, которую не отметили после окончания, автоматически становится пропущенной; её можно исправить на «вовремя» или «позже».
- **Перенос:** +30 минут, +1 час, на вечер, на завтра, а также сдвиг всего остатка дня на +30 минут.
- **Повторы:** по дням недели. Задачи создаются на эту и следующую неделю и автоматически продлеваются.
- **Уведомления:**
  - за 30, 15 или 5 минут и в момент начала, в любом сочетании;
  - настойчивые повторы: каждые 3–15 минут, до 2–5 раз;
  - вопрос «как прошло?» в конце задачи;
  - кнопки прямо в уведомлении: «Готово», «+10 минут», «Перенести».
- **Напоминание о переподписи:** срок подписи читается из самого приложения.
- **2 недели:** мини-таймлайн каждого дня, нагрузка в часах и процент выполнения.
- **Итоги:**
  - продуктивность: вовремя = 1, позже = 0,5, пропуск = 0;
  - разбивка по дням и категориям, сравнение с прошлым периодом;
  - подсказка, какую задачу ты чаще всего пропускаешь.
- **Шаблоны дня:** «Рабочий день» и «Выходной» для пустого дня.

## Известные ограничения

- **Кнопки «Готово» и «+10 минут» в уведомлении** срабатывают, если приложение висит в фоне. Если приложение было полностью закрыто (смахнуто), iOS может не передать нажатие. Тогда отметь задачу в самом приложении.
- **Виджеты на экране блокировки** запланированы на следующую версию. Их работа с бесплатной подписью ещё не проверена.

## Для разработки

```bash
npm install
npx tsc --noEmit   # проверка типов
npx expo start     # дев-сервер
```

Стек: Expo SDK 57, React Native 0.86, Reanimated 4, Gesture Handler, expo-sqlite, expo-notifications, expo-glass-effect (Liquid Glass на iOS 26).
