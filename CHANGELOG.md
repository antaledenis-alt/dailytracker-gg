# История изменений

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии следуют [семантическому версионированию](https://semver.org/lang/ru/).

## [0.2.0] — 2026-10-02

### Добавлено

- Сборка для Android (`Planner.apk`) в GitHub Actions.
- Канал уведомлений Android и разрешение на точные напоминания.
- Обработка системной кнопки «Назад» на Android: закрывает шторки, затем возвращает на экран «Сегодня».
- Документация: установка на iOS и Android, способы обойти ограничение в 7 дней, руководство разработчика.

### Изменено

- Сборки для iOS и Android объединены в один процесс с общим релизом.
- Релизы именуются `v<версия>-build.<номер>`.
- На Android скрыты элементы, связанные с подписью iOS.

## [0.1.1] — 2026-10-02

### Исправлено

- Установка через SideStore: основное имя приложения заменено на латинское `Planner`, русское название «Планер» перенесено в локализацию.

## [0.1.0] — 2026-10-02

### Добавлено

- Экран «Сегодня»: временная шкала, карточка текущей задачи, перетаскивание задач, свайп между днями.
- Создание и редактирование задач, повторы по дням недели, шаблоны дня.
- Статусы задач и автоматическая отметка пропущенных.
- Локальные уведомления, настойчивые повторы, кнопки действий.
- Напоминания о продлении бесплатной подписи iOS.
- Экраны «2 недели» и «Итоги».
- Сборка неподписанного `Planner.ipa` в GitHub Actions.
